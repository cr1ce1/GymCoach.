# Gym Trainer AI

Dark/neon-lime responsive fitness website prototype.

## Publish
Upload `index.html` to the root of your GitHub repository. Then open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.

## Limitations
This is a demo. Login details and profile/workout data are stored in the browser, not a secure backend. The coach uses simple preset replies and is not connected to a real AI model. Image/video technique analysis is not implemented. Do not use this demo for sensitive data.
